# 素材候选清单（调研结果）

> **性质说明**：本文档是**候选调研**，不是最终采用清单。
> 最终采用哪些来源由项目负责人确认，并在 M7 阶段补全**署名义务登记**。
>
> 风格要求：**卡通风（Cartoon / Stylized）低多边形**（决策 D-16）。
> 技术前提：Unity 6000.6.0f1 + URP 17.6.0，素材必须 URP 兼容或可安全转换。
> 平台范围：**仅 Windows**（决策 D-15）。
>
> 核实日期：2026-09-10
> 核实方式：实际请求各站点首页/资源页，记录 HTTP 状态码；许可证信息来自各站点公开的授权说明页。

---

## 1. 结论速览

**推荐组合（4 个主力来源即可覆盖全部类别）：**

| 来源 | 覆盖类别 | 授权 | 为什么选它 |
| --- | --- | --- | --- |
| **Kenney** | 角色占位、武器、道具、UI、音效 | **CC0** | 卡通低多边形风格的标杆；CC0 无署名义务；类别覆盖最广，一个站点可解决大半需求 |
| **Quaternius** | 角色、场景建筑、道具、动画 | **CC0** | 有专门的科幻/都市/动画库资源包，与本项目题材最贴近；同样无需署名 |
| **KayKit** | 角色、地牢场景模块、道具 | **CC0** | 卡通风格统一且质量高；模型比例规整，适合斜俯视 |
| **Freesound** | 枪声、脚步、环境音 | CC0 与 CC-BY 混合，**逐个核对** | 音效库最全；必须逐条确认授权 |

**备选/补充**：Poly Haven（HDRI 环境光照）、OpenGameArt（补充冷门资源，需逐个核对授权）、Game-icons.net（UI 图标，**CC-BY 必须署名**）。

## 3. 许可有坑 / 不建议用于作品集

以下来源**不建议**用于会公开传播的求职作品集，原因各不相同：

| 来源 | 问题 | 结论 |
| --- | --- | --- |
| **Fab**（fab.com） | 返回 `403`，且平台以付费资源为主，各资源授权条款独立 | 除非明确购买并确认可商用授权，否则不用 |
| **Pixabay** | 返回 `403`；且部分素材含第三方商标或肖像 | 无法核实，不用 |
| **Unity Asset Store 免费资源** | **授权条款因包而异**，部分严禁再分发或要求购买方账号绑定 | 逐个阅读条款后再决定，默认不用 |
| **任何标注"个人使用免费、商用收费"的资源** | 求职作品属于公开传播 | **绝对不用** |
| **GPL / CC-BY-SA 授权的素材** | 具有传染性，可能要求衍生作品以相同协议开源 | **绝对不用** |
| **来源不明的模型站（如各类"免费模型下载"站）** | 多为盗传，存在版权风险 | **绝对不用** |
| **游戏内提取的资源**（从其他游戏扒出的模型/贴图/音效） | 明确侵权 | **绝对不用**——作品集会公开传播，风险极高 |

> **核心原则**：宁可画面朴素，也不引入授权不明的素材。本项目美术方向是卡通低多边形，Kenney + Quaternius 两个 CC0 来源已足够覆盖大部分需求，没有任何理由承担版权风险。

## 4. 技术注意事项

### 4.1 URP 兼容性

绝大多数免费低多边形资源使用**内置渲染管线（Built-in）的标准材质**。导入 URP 项目后会出现**粉色材质**，这是最常见的坑。

**处理方法**（按优先级）：

1. 优先选择提供 URP 版本的资源包（Kenney 的部分资源提供通用材质）
2. 使用 Unity 菜单 `Edit → Rendering → Materials → Convert Selected Built-in Materials to URP`
3. 若转换效果不佳（卡通风格常因 Shader 差异失真），**重新指定一个自定义卡通材质**——本项目采用扁平色块，重新赋材质的效果通常比自动转换更好

> M7 阶段的验收条件之一：**所有导入素材的材质均由本项目统一管理，不依赖资源包自带 Shader**（见主文档 4.4 节）。

### 4.2 动画来源的取舍顺序

本项目最缺的类别是**人形角色动画**（持枪移动、射击、受击、死亡）。建议按以下顺序尝试：

1. **Quaternius Universal Animation Library**（CC0，无需账号）—— 优先验证是否够用
2. **Kenney 角色动画**（CC0）
3. **Mixamo**（需 Adobe 账号）—— 前两者不足时的兜底方案

### 4.3 模型比例与斜俯视适配

不同来源的模型比例不一致（有的 1 单位 = 1 米，有的不是）。批量导入时**必须统一缩放标准**，否则在斜俯视下会出现大小混乱。

建议：在 M7 导入前先定下"1 Unity 单位 = 1 米"的基准，并在导入检查中验证角色高度（约 1.8 单位）与门框高度。
