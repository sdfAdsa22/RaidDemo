## 2. 技术标准（已定稿，无需选择）

### 2.1 比例与尺寸基准

| 项目 | 基准 | 说明 |
| --- | --- | --- |
| 世界比例 | 1 Unity 单位 = 1 米 | 与现有灰盒一致，不改引擎刻度 |
| 玩家角色 | 高 1.8 米，胶囊半径 0.4 米 | 与现有 `CapsuleCollider` 一致，替换后不得改变碰撞体 |
| 敌人角色 | 高 1.8 米（±5%） | 与玩家同规格，便于共用动画与感知参数 |
| 建筑层高 | 4 米 | 灰盒墙高；替换模块净高不得低于 3.2 米，否则影响相机穿墙观感 |
| 装卸平台 | 高 1.2 米，配 3.5 米坡道 | 与战局地图既有台座/坡道一致，替换后必须复测通行 |
| 集装箱 | 长 6.06 × 宽 2.44 × 高 2.59 米 | 按 20 尺标准箱比例，卡通风格可微调造型但保留比例关系 |
| 小道具（箱/桶/货架） | 高 0.5~1.4 米 | 俯视角可读性优先；过小的物件放大 10%~20% |

**铁律：只换外观，不改碰撞与导航。** 新模型的包围盒需贴合原灰盒占位体；若必须改变碰撞体积
（门洞、坡道、掩体边缘），该批次必须重跑移动/AI 回归测试并重新烘焙 NavMesh。

### 2.2 目录结构

```text
Assets/Game/Content/
├─ External/                 # 第三方原始资源：只读，不手改、不重命名
│   ├─ _Inbox/               # 候选暂存区：已加入 .gitignore，试用素材不入库
│   ├─ Kenney/<资源包名>/
│   ├─ Quaternius/<资源包名>/
│   └─ KayKit/<资源包名>/
└─ Art/                      # 项目自有美术资产：可改，逻辑唯一引用入口
    ├─ Characters/           # 角色预制体 + Animator
    ├─ Props/                # 场景道具、容器、掩体预制体
    ├─ Items/                # 物品模型预制体（含挂点）
    ├─ Materials/            # 统一材质库
    ├─ Animations/           # 动画控制器与动画剪辑引用
    └─ UI/                   # 图标、九宫格、字体、UI 音效引用
```

规则：`External/` 内的资源**不允许被场景或代码直接引用**，一律经 `Art/` 下的项目层预制体引用。
这样将来换素材时，只需修改预制体内部引用，场景与逻辑零改动。

**候选素材入库规则（负责人 2026-09-12 确认）：**

1. 候选素材一律先下载到 `External/_Inbox/`，该目录已在 `.gitignore` 中，**不会进入 Git 历史**。
2. 在 Unity 中导入、试装、对比观感；淘汰的素材直接删除，不留下任何提交记录。
3. 只有负责人**最终确认采用**的版本，才从 `_Inbox/` 移到 `External/<来源>/<资源包>/` 并提交。
4. 每个采用包必须连同包内 `LICENSE` 一起提交，未采用的包不提交、不保留分支历史。

### 2.3 材质与 Shader 规则

- 所有外部模型导入后**重新赋本项目材质**；不使用资源包自带 Shader（内置管线会显示为粉色，HDRP 材质无法直接用于 URP）。
- 首选 `Universal Render Pipeline/Lit` 简化配置：Opaque、Metallic 0、Smoothness 0.05~0.2、纯色或小色块贴图。
- 卡通描边（可选）用 URP Renderer Feature 做背面外扩，只对角色与关键道具开启；性能回测通过后再决定是否保留。
- 贴图尺寸 ≤ 2K，默认 512/1024；PC 平台压缩用 DXT5/BC7；卡通风格不需要法线贴图与金属度贴图。
- 材质数量收敛：同一资源包内合并同色材质，**全场材质目标 ≤ 30 个**，避免 Draw Call 膨胀。

### 2.4 骨骼、动画与挂点

- 人形角色统一 **Humanoid** 骨骼，Avatar 由项目生成并复用，动画可跨来源共享。
- 优先选择"动画与模型分离"的资源包；动画剪辑统一复制/引用到项目层 `Art/Animations/`，避免替换 `External/` 时丢引用。
- 挂点命名统一：`Socket_Weapon`、`Socket_Head`、`Socket_Back`、`Muzzle`，挂在项目层预制体上；动画只驱动骨骼，不承载逻辑。
- **严禁用动画事件触发伤害、换弹、消耗等结算**：逻辑时序由 Simulation 层决定，动画只做表现。
- 脚步动画的位移速度必须与现有步行/奔跑参数对齐，必要时在 Animator 里调整播放速度，避免滑步。

### 2.5 面数与贴图预算

| 类别 | 单模型三角面 | 贴图 |
| --- | --- | --- |
| 玩家 / AI 角色 | ≤ 8,000 | 1024 |
| 武器 | ≤ 3,000 | 512~1024 |
| 装备（头盔/护甲/背包） | ≤ 1,500 | 512 |
| 主要场景模块（建筑/集装箱） | ≤ 3,000 | 1024 |
| 小道具（箱/桶/货架） | ≤ 800 | 512 |
| UI 图标 | 2D，≤ 256×256 | — |

- 同屏三角面预算：**≤ 50 万**（对应 1080p 60 FPS 目标，见主文档 8.2 节性能预算）。
- 每个资源包导入后统计一次总面数与贴图体积，记录到 M7 排障手册，作为批次 2 的验收依据。

### 2.6 命名与引用规则

- `External/` 下保持来源原始文件名（便于对照授权与升级）；项目层预制体使用项目命名（PascalCase，见主文档 5.1 节）。
- 场景、Prefab、代码只引用 `Art/` 下的项目层资产；替换素材时只改预制体内部引用。
- 禁止把 External 资源放进 `Resources/`；后续若需热更，改走 Addressables（ADR-002）。
- 文件名不得含中文、空格与绝对路径（`PathRulesTests` 会拦截）。

### 2.7 URP 兼容性处理流程

1. 优先选择明确标注 URP / 通用管线的资源包。
2. 内置管线资源：`Edit → Rendering → Materials → Convert Selected Built-in Materials to URP`。
3. 转换失真（卡通风格常见）则丢弃其材质，直接重赋项目材质。
4. 导入后确认 Console 无粉色材质、无 Shader 报错、无缺失贴图引用。
5. HDRP 专属资源直接放弃，不尝试转换。

### 2.8 授权与署名规则

| 处理方式 | 授权类型 | 说明 |
| --- | --- | --- |
| 直接采用 | CC0 / 公有领域 | 无需署名，仍登记来源以备查 |
| 采用但登记 | CC-BY、MIT 等允许商用与再分发的授权 | 必须登记名称、作者、链接、协议 |
| 禁止采用 | CC-BY-NC / CC-BY-ND、仅个人使用、无授权声明、来源不明搬运包 | 作品集公开传播存在法律风险 |

- 每个资源包下载时保存包内 `LICENSE` / `README` 到 `External/<来源>/<包>/_License/`，随仓库提交（体积小）。
- 最终采用清单统一登记到 README「素材来源清单」（对应主文档 11.4 节第 7 条）。
- Mixamo 等"免版税但限制再分发"的服务只作兜底：若要使用，先确认条款并只保留在本地，不把原始文件提交到公开仓库。

### 2.9 Git LFS 规则（批次 0 已启用）

- 自 M7 批次 0 起 `.gitattributes` 启用 LFS，覆盖四类：
  1. 3D 模型：`fbx / obj / blend / gltf / glb / dae / stl`
  2. 贴图：`png / jpg / jpeg / tga / psd / tif / tiff / exr / hdr`
  3. 音视频：`wav / mp3 / ogg / aiff / flac / mp4 / mov / webm`
  4. 资源包归档：`unitypackage`
- 本地已执行 `git lfs install --local`（钩子写入 `.git/hooks`，不入库）；协作者克隆后需安装 Git LFS，否则拿到的是指针文件。
- 未走 LFS 的小体积二进制（ttf / otf / dll / so 等）保持普通存储。
- **不追溯迁移历史文件**：仓库已有的 PNG 等文件继续以普通对象存在于历史中，此后新增或修改的才走 LFS（避免重写历史）。
- 注意 GitHub LFS 免费额度（存储与月流量各 1 GB），超出后需评估；因此只入库"确定采用"的素材。

## 3. 主要风险与规避

| 风险 | 表现 | 规避手段 |
| --- | --- | --- |
| 比例不统一 | 角色与门框、集装箱大小混乱 | 导入即按 2.1 节基准逐项检查 |
| 材质转换失败 | 模型显示粉色、光照异常 | 禁用资源包 Shader，统一重赋项目材质 |
| 动画不匹配 | 手部穿模、滑步、持枪姿态错位 | 统一 Humanoid + 项目 Avatar，脚步速度对齐移动参数 |
| 碰撞被改坏 | 卡位、穿墙、AI 卡住 | 只换外观；改动碰撞必须重烘焙 NavMesh 并回归测试 |
| 仓库体积膨胀 | 克隆缓慢、LFS 额度超限 | 只提交采用素材；LFS 覆盖大文件；未选资源不入库 |
| 授权踩坑 | 作品集公开传播的法律风险 | 2.8 节规则 + README 来源清单 + 保留授权文件 |
