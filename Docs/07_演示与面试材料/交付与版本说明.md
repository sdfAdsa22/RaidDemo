> 面向面试官与验收者；操作细节以 `Tools/Launcher/README.md`、`Tools/UpdateSource/README.md` 与 `deploy/README.md` 为准。

## 一、交付物

| 产物 | 说明 |
| --- | --- |
| 启动器版整包 | `RaidDemo-启动器版.zip`：启动器 + 客户端 + Windows / Linux 服务端 + 更新源工具 |

## 二、怎么装、怎么玩

**单机**：解压启动器版整包 → 双击客户端 `RaidDemo.exe` → 主菜单 → 开始 → 安全屋。

**启动器（推荐）**：双击 `RaidDemo.Launcher.exe` → 选择更新源（本机 / 云主机 / 自定义）→
检查更新 → 更新并启动。安装目录、更新源地址都可在界面里切换。

**联机**：

```powershell
# 服务器（Windows 双击 RaidDemo.ServerHost.exe 更简单）
RaidDemo.exe -server -port 7777 -room 演示房间 -autostart 20 -raidDuration 480

# 客户端（不同机器各跑一条；同机多开需改 -nickname）
RaidDemo.exe -connect <服务器IP>:7777 -nickname 甲 -autoroom
```

服务器状态页（浏览器查看房间与玩家，支持踢人 / 解散等运维操作；写操作需管理口令）：
`http://<服务器IP>:8080/`。

## 五、已知边界

仅 Windows 客户端；一台服务器承载一个房间；2~4 人合作 PVE、无 PVP 与反作弊；
进程内代码热更不可用（按 ADR-008 降级为启动器更新本体）；内容规模为 1 张地图、5 个固定任务。
完整清单见仓库根 `README.md` 的「已知限制」与 [`../02_架构与工程.md`](../02_架构与工程.md) 的「范围边界」。
