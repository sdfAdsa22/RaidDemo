## 二、玩家怎么装

**方式一：直接玩单机**

解压 `RaidDemo-1.0.0-win64.zip`，双击 `RaidDemo.exe`。主菜单 → 开始 → 安全屋。

**方式二：走启动器（推荐，能更新）**

```powershell
# 1) 起一个更新源（本机演示；也可指向云主机）
RaidDemo.UpdateSource.exe --root <更新源目录> --port 8090 --token <口令>

# 2) 启动器：全量安装 + 启动
RaidDemo.Launcher.exe --update --source http://127.0.0.1:8090 --root <安装根> --launch
```

图形界面：双击 `RaidDemo.Launcher.exe` → 选更新源 → 检查更新 → 更新并启动。

**联机**（同一局域网内）

```powershell
RaidDemo.exe -server -port 7777 -room 演示房间 -autostart 20 -raidDuration 480
RaidDemo.exe -connect <服务器IP>:7777 -nickname 甲 -passphrase 246810 -autoroom
```

## 三、相对上一版（0.10.1）的变更

这一版没有加新玩法，全部是**自审 → 复核 → 分批修**的结果：

### 第一批（提交 `3a901bb`）

- 体力恢复不再比配置慢 1 秒（配置 1.5 / 3 秒现在真的是 1.5 / 3 秒）；
- AI 穿透力改回与护甲同一根刻度（原来对任何有效护甲都打不穿）；
- 仓库满时撤离入库**不再销毁战利品**（留在背包里等玩家清理仓库）；
- 装备命令入口加合法性校验（非法槽位与未知种类一律丢弃）；
- 上行移动/朝向做有限性校验（NaN / Infinity 整包丢弃）；
- 昵称与房间名补 UTF-8 字节上限（中文名不再被协议静默截断）；
- Cinemachine 版本对齐、README 状态口径更新。

### 第二批（提交 `d88b9ed`，联机权威链）

- **服务器补上战局总时长**（`-raidDuration`，默认 480 秒）——以前"这一局什么时候结束"由客户端说了算；
- 本局用时改用开局时刻（原来会混进服务器开机时长）；
- 结算击杀数、带出价值（含全部装备槽）都由服务器算准；
- 客户端不再自行结算，结算面板改用服务器下发的价值 / 击杀 / 用时；
- 联机结算不再改动本地单机进度；
- 联机医疗品改由服务器执行（回血、扣物品、只给本人回血事件）；
- 修掉"服务器说时间耗尽、客户端显示阵亡"的映射错误。
