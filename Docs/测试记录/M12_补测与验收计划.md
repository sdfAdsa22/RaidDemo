### 批次 1 · Unity 编辑器补测（单机域）

先跑全量 EditMode / PlayMode 回归（基线 716 / 4），再按 M11 报告 4.1 清单补测：

- 搜刮读条与物品转移（含 Shift+右键拆分、右键菜单、双击快速转移）
- 拖拽 / 双击（编辑器内 UI 事件驱动；驱动不了时由负责人手动补一步）
- 医疗品 H 使用（受伤打断、不消耗）、弹药挂取弹、负重变化过程
- R 换弹、滚轮切枪、护甲 / 头盔减伤数值、弹道与准星一致性
- 商人批量出售模式、任务接取 / 交付、图鉴收集与点击、靶子伤害数字、衣柜选角色
- 弹道逐帧（暂停 + 步进）、F1 视野锥 / 听觉圈参数逐项核对
- 西坡顶撤离路线、返回桌面（= 停止 Play）、音效听测、Profiler 帧时间采样

### 批次 2 · 联机多进程补测 + 修复

连同批次 1 发现的问题一起修，补 EditMode / PlayMode 回归用例，修完复测受影响项。

### 批次 3 · 出 1.0.2 产物 + 本地冒烟

- 修复门槛：阻断级与中危必修；低危显示口径一并修；复现不了的只补齐记录与复现步骤，不阻塞发布。
