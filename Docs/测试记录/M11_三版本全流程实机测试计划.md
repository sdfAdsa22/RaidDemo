## 三、测试矩阵

### 批次 1 · 单机版（2 轮）

- **驱动**：窗口化交付客户端 + 系统级键鼠注入。
  开测第一件事做**输入预检**（F1 面板可开、主菜单可点）：
  预检通过 → AI 直接操作；预检失败 → 单机两轮改为人工操作，AI 负责环境、取证与记录，
  并在报告标注「单机为人工执行」。
- **轮 1（新档）**：隔离单机存档 → 主菜单 → 新游戏 → 安全屋（商人买卖 / 批量出售 /
  仓库拖拽与右键 / 衣柜 / 靶子伤害数字 / 测试箱 / 出口 1 可用 + 2 上锁）→ 进图 →
  搜刮（拖拽 / 双击 / Shift+右键拆分 / 右键菜单 / H 使用医疗 / 弹药挂 / 负重）→
  战斗（弹道与准星 / 射程 / 换弹 / 滚轮切枪 / 护甲头盔减伤 / HUD）→
  AI（巡逻 / 警惕 / 攻击 / F1 范围可视化）→ 撤离 → 结算 → 回屋 → 暂停菜单 → 退出。
- **轮 2（续档）**：继续游戏 → 核对存档（装备 / 仓库 / 金币 / 任务）→ 进图 →
  本轮走阵亡路径 → 回屋复查损失清单 → 返回桌面。
- **每轮附带**：帧率与卡顿点、鼠标隐藏与准星、Esc 各界面、图鉴、操作说明、
  日志异常堆栈（即使不计功能缺陷也要记录）。

### 批次 2 · 本地服务器版（2 轮）

- **环境**：Windows 一键开服面板（ServerHost + `RaidDemoServer.exe`），
  `server.config.json` 指向独立测试存档 `server_saves_e2e`，`-grace 60`、看门狗默认 2.5s。
- **轮 1（2 人）**：客户端 A 用「启动器本机源全量下载安装」的副本走联机界面 UI 路径建房；
  客户端 B 用交付客户端命令行参数加入（`-connect 127.0.0.1 -port 7777 -nickname e2e02
  -passphrase <6 位> -autoroom`）。覆盖共享安全屋门禁、出击、进图同步
  （移动 / 朝向 / 枪械 / 弹道 / 换弹 / 容器 / 救援）、撤离与阵亡、结算、共享仓库落库、
  金币与任务、返回主菜单；含 1 次强杀 B → 宽限自愈 → 重启换绑回局。
- **轮 2（4 人）**：1 服务端 + 4 客户端（2 窗口 + 2 无头 `-batchmode -nographics -autowalk`），
  `-autostart` 自动开局；覆盖核心链路 + 房主退出回归 + 两端 `profiles.json` 一致性核对。
- **账号**：`e2e01 ~ e2e04` 全新测试存档，不碰既有进度。

### 批次 3 · 云服务器版（2 轮）

- **轮 1（2 人）**：客户端 A 用「启动器选云主机 → 选安装目录（自动建 `RaidDemo`
  子目录）→ 全量下载 → 复检无更新 → 启动」的副本；房主 UI 建房、B 加入；
  覆盖批次 2 核心链路 + 公网延迟观感 + 云状态页/云日志交叉核对 + 云存档落库。
- **轮 2（4 人）**：2 窗口 + 2 无头；含第二次断线自愈复测与撤离/阵亡双路径。
- **分发负例**（并入本轮）：停掉本机更新源点「检查更新」→ 应给出失败提示且旧版本仍可启动；
  用 `Builds/Client/0.10.1` 旧客户端连云服 → 应被版本握手拒绝并提示两个版本号。

- 每个检查点记 **PASS / FAIL / BLOCKED**；FAIL 必含：复现步骤、期望 vs 实际、

## 五、关键接口与命令（全部为现有能力）

- 构建：`unity command --project-path "D:\unity game\demo" --timeout 1500 menu
  --path "RaidDemo/M9/构建专用服务器（Windows|Linux）"`
- 组装：`pwsh -NoProfile -File Tools/Release/assemble_delivery.ps1
  -ClientDirectory "Builds\Update\1.0.0\body"`
- 更新源：`POST /api/upload?version=1.0.0&overwrite=true`、
  `POST /api/publish?version=1.0.0`、`GET /api/verify?version=1.0.0`（头 `X-Auth-Token`）
- 部署：`scp` + `./server.sh restart|status|logs`、`deploy/updatesource.sh`
- 客户端：`RaidDemo.exe [-connect <ip> -port 7777 -nickname <n> -passphrase <4~6 位>
  -autoroom [-autowalk] [-autotrade]]`
- 服务端：`RaidDemoServer.exe -server -port 7777 -saveDir server_saves_e2e -grace 60`

- 4 人轮若本机资源不足，降级为 3 人（2 窗口 + 1 无头）并在报告记录降级原因，不额外增加轮次。

- 本轮发现的缺陷**只记录不修复**；修复排期等测试报告出来后另行安排。
