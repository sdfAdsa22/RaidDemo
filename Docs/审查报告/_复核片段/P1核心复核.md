## 二、对第七节结论的三条输入

1. **第一批修复范围应维持 14 条 P1，但顺序需要微调**：`041` + `042` 是"联机权威链是否闭合"的开关，
   `043` + `044` 是"本地状态污染"的两条腿。先修 `043`（隔离）再修 `044`（上报治疗），
   否则会先把联机治疗接到服务端、却仍让本地进度被污染。`045`（击杀统计）应与 `049` 一起做，否则修完界面会立刻暴露 0 击杀。
2. **`027` / `028` / `010` / `011` 是四条"改一处就见效"的小修**（穿透力量纲、入库回滚、恢复延迟、物品状态绑定），
   建议放在第一批尾部单独提交，每一条都配一个能复现旧行为的测试。
3. **必须实机确认的 5 条**：`012`（弹匣/容器广播覆盖度）、`041`（客户端能否本地结束战局）、
   `043`（单机存档字节是否被联机污染）、`044`（联机使用医疗品的实际表现）、`047` / `048`（需要注入验证的输入与登录安全）。
   其中 `041` 与 `043` 优先级最高——它们决定"联机这一层能不能先冻结"。
