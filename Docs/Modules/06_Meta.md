---

## 1. 定位

M5 让「一局」成立了；M6 要让**很多局连成一条进度线**。

| | M5 结束时 | M6 完成后 |
| --- | --- | --- |
| 战利品 | 结算界面如实显示，但不真正保存 | 撤离成功后**真的进仓库** |
| 阵亡 | 只显示「损失了多少」 | 随身装备**真的没了** |
| 出击 | 永远光手出门 | 从仓库挑装备带走 |
| 玩家的问题 | 「这一局我贪对了吗」 | **「我的仓库在变好还是变差」** |

---

## 2. 目标循环

```text
仓库：挑装备、看家底
   ▼
出击准备：决定带什么（带多少 = 冒多大风险）
   ▼
战局：搜刮、交火、决定撤还是贪
   ├─ 撤离成功 → 带出的东西真的进仓库
   └─ 阵亡 → 随身装备真的没了
   ▼
商人：战利品变卖成钱，用钱买下一套装备
   ▼
任务：带着「这局要做什么」的明确目标再出击
```

---

## 3. 已确认规则（2026-09-12）

| # | 规则 | 结论 |
| --- | --- | --- |
| 1 | 撤离成功 | 背包 + 身上装备**全部**带出，进仓库 |
| 2 | 阵亡 | 背包里的 + 身上穿的**全部丢失**（真的从仓库扣除） |
| 3 | 时间耗尽 | 与阵亡同档处理（都是失败） |
| 4 | 仓库 | **绝对安全**：只有撤离成功才能进去，没有任何方式从中损失 |
| 5 | 出击准备 | 从仓库挑装备带上；**不带背包就只有 5×5 口袋**（沿用 M5.6 的规则） |
| 6 | 开局装备 | 不做默认配置，玩家从零开始，靠商人购买 |

> **第 1、2 条合起来产生的曲线**：玩家天然会「好装备存着，穿一套输得起的出门」——
> 这正是搜打撤最健康的心态：不是不怕死，而是事先算好这一趟输得起多少。
> 副作用是**新手期几乎无损**（光手出击），越富越痛，难度曲线自动跟着财富走。

## 4. 四个批次

每个批次结束时**游戏都必须是完整可玩的**——不能出现「仓库做了一半、出击崩了」。

### 批次 1：让战利品有归宿（最大的一批）

**玩家感受**：撤离带出的东西真的存下来了，下一局能带着它出击。

| 包含 | 说明 |
| --- | --- |
| 仓库 | 跨战局保存；容量无限；按类型/价值排序；双击快速存取 |
| 结算接真实存储 | 撤离成功 → 带出物进仓库（M5 只是显示） |
| 出击准备 | 从仓库拖装备到装备槽，背包里装弹药与消耗品 |

**内部三个小步**（每步结束都能玩）：
1. 仓库本身（存储、排序、双击存取）
2. 结算接真实存储（带出的东西进仓库）
3. 出击准备（从仓库挑装备带进战局）

**完成判据**：搜到一把 AK → 撤离 → 仓库里看到它 → 下一局带着它出击，战局里手上就是它。
**本批不做**：阵亡扣装备（仍按 M5 的「如实显示」）。
**工作量**：约 0.8 个 M5。

### 批次 2：让玩家真的怕死（最小但最关键）

**玩家感受**：死一次，身上那套装备就没了；仓库是唯一的安全区。

**完成判据**：带着一套装备出击 → 阵亡 → 回仓库发现那套装备真的没了。
**工作量**：约 0.3 个 M5。**它是整个 M6 的情绪核心**——做完这一批，游戏才第一次有得失。

### 批次 3：让钱有意义

**玩家感受**：战利品能卖钱，钱能买到更好的装备，「该不该贪」有了价值尺度。

**完成判据**：空仓库、光手出击 → 连打两三局卖东西 → 攒够钱买下第一套中档装备。
**工作量**：约 0.6 个 M5。

### 批次 4：让循环有理由、进度留得住

**玩家感受**：有明确的小目标，而且关掉游戏再打开进度还在。

**完成判据**：连打 3~4 局后重启游戏，仓库、钱、任务进度都在，经济曲线成立。
**工作量**：约 0.6 个 M5。

---

## 5. 经济目标曲线（批次 3 用）

现在的物品价值差距过于极端：铜螺栓 600、金表 32,000、防弹背心 15,000。
批次 3 要重排一次，让「一局能赚多少」与「死一次亏多少」落在同一量级。

| 项 | 目标值 |
| --- | --- |
| 一次成功撤离（搜 3~4 个箱子） | **15,000 ~ 40,000** |
| 一套中档装备（手枪 + 钢盔 + 背心 + 背包） | **≈ 20,000** |
| 设计意图 | **死一次要打两局才回本**——让人犹豫，但不劝退 |

## 6. 明确不做

| 不做的事 | 归属 |
| --- | --- |
| 多个商人 / 声望 / 玩家间交易（跳蚤市场） | 不做，超出作品集范围 |
| 随机生成任务 | 不做，固定任务足够 |
| 枪械改装、皮肤 | 不做 |
| 保险箱（阵亡保留部分物品） | 留待 M7 之后 |
| 云存档 | 不做 |
| 战局中途存档 | 不做，只存局外进度 |

## 7. 风险

| 风险 | 应对 |
| --- | --- |
| **存档被低估** | 批次 4 只做「极简存档」：仓库、钱、装备、任务进度；不碰战局中途状态。一旦有存档，就要处理版本兼容与损坏，这一条必须留出时间 |
| 界面工作量被低估 | 仓库与出击准备都是新界面（排序、拖拽、分栏），比逻辑层更花时间 |
| 经济数值失控 | 批次 3 先按第 5 节的曲线配，再靠真实游玩调整；数值全部外置可改 |
| 玩家在批次 1、2 之间「没有理由出门」 | 这两批不解决「为什么去」，那是批次 4 的任务；在演示时用「仓库在变好」作为动机说明 |
