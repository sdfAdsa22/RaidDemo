## 1. 定位

M5 让「一局」成立了；M6 让**很多局连成一条进度线**。

| | M5 结束时 | M6 完成后 |
| --- | --- | --- |
| 战利品 | 结算界面如实显示，但不真正保存 | 撤离成功后**真的进仓库** |
| 阵亡 | 只显示「损失了多少」 | 随身装备**真的没了** |
| 出击 | 永远光手出门 | 从仓库挑装备、买装备带走 |
| 玩家的问题 | 「这一局我贪对了吗」 | **「我的仓库在变好还是变差」** |

---

## 2. 目标循环

```text
仓库：挑装备、看家底（金币 / 仓库总价值常驻显示）
   ▼
出击准备：决定带什么（带多少 = 冒多大风险）
   ▼
战局：搜刮、交火、决定撤还是贪
   ├─ 撤离成功 → 战利品真的进仓库，任务进度结算
   └─ 阵亡 / 超时 / 强退 → 随身装备与物资真的丢失
   ▼
商人：战利品变卖成金币，用金币买下一套装备
   ▼
任务：接取目标 → 出击完成 → 回安全屋领奖 → 解锁后续任务
```

---

## 3. 已确认规则（2026-09-12）

| # | 规则 | 结论 |
| --- | --- | --- |
| 1 | 撤离成功 | 背包 + 身上装备**全部**带出，进仓库 |
| 2 | 阵亡 / 超时 | 背包里的 + 身上穿的**全部丢失**（真的从仓库扣除） |
| 3 | 战局中途强退 | **与阵亡同档处理**：清空随身携带物，仓库不受影响 |
| 4 | 仓库 | **绝对安全**：只有撤离成功与交易才能改变它 |
| 5 | 出击准备 | 从仓库挑装备带上；**不带背包就只有 5×5 口袋**（沿用 M5.6 的规则） |
| 6 | 开局 | 不送装备，给 **5,000 金币**启动资金，第一件事是去商人处购买 |

> **第 1、2 条合起来产生的曲线**：玩家天然会「好装备存着，穿一套输得起的出门」——
> 这正是搜打撤最健康的心态：不是不怕死，而是事先算好这一趟输得起多少。
> 副作用是**新手期几乎无损**（光手出击），越富越痛，难度曲线自动跟着财富走。

## 4. 批次 1：仓库 + 出击准备 ✅

**玩家感受**：撤离带出的东西真的存下来了，下一局能带着它出击。

| 包含 | 说明 |
| --- | --- |
| 仓库 | 跨战局保存；固定 10×8 网格；按类型/价值整理；双击快速存取 |
| 结算接真实存储 | 撤离成功 → 带出物进仓库（M5 只是显示） |
| 出击准备 | 从仓库拖装备到装备槽，背包里装弹药与消耗品 |

**完成判据**：搜到一把 AK → 撤离 → 仓库里看到它 → 下一局带着它出击，战局里手上就是它。

## 4.1 批次 2：阵亡真的扣装备 ✅

**玩家感受**：死一次，身上那套装备就没了；仓库是唯一的安全区。

**完成判据**：带着一套装备出击 → 阵亡 → 回仓库发现那套装备真的没了。

**实现点**：`MetaProgress.ClearLoadout()`。仓库网格与随身携带物是两批独立数据，
只有撤离成功时才会调用 `DepositLoadoutToStash()`。

## 4.5 批次 2.5：安全屋 ✅

### 它解决什么

把「局外系统」从一个菜单变成**一处能走动的空间**：出击前的准备动作
（走到仓库前存装备、到靶子前试枪、从出口选地图）全部发生在场景里，而不是面板里。

### 空间里有什么

| 设施 | 位置 | 交互 |
| --- | --- | --- |
| 仓库 | 北墙西侧 | 按 `E` 打开背包界面，右侧面板显示仓库 |
| 商人 | 北墙中间 | 按 `E` 打开交易界面：购买 / 出售 / 任务 |
| 出口 | 北墙东侧 | 按 `E` 打开地图选择：工业区可用 + 港口 / 农场上锁，按 `1` 出击 |
| **测试箱** | 仓库前方 | 按 `E` 打开，固定产出武器 / 护甲 / 头盔 / 背包（**交付前删除**） |
| **靶子** | 东侧三个 | 可以开枪，命中处冒伤害数字，打中靶心显示金色 |
| 操作说明牌 | 北墙 | 世界空间画布，说明已从主菜单搬到这里 |

### 战斗装配

安全屋与战局共用**同一套武器链路**（`PlayerWeaponController` + 同一批命令），
差别只有两条：没有 AI、没有战局会话。靶子会登记成战斗单位，
因此命中判定、伤害计算与伤害事件全部走现成链路，不必为「打靶」另写一套弹道。

## 4.6 批次 3：商人 + 经济重排 ✅

### 商人界面

商人从占位 NPC 变成真正的交易终端，走近按 `E` 打开。

| 区域 | 内容 |
| --- | --- |
| 顶部页签 | `购买` / `出售` / `任务` |
| 购买页 | 固定货架列表：名称、单价、一组数量与总价；点击「购买」直接进仓库 |
| 出售页 | 右侧仓库网格；左键选中、右键直接出售；选中后也可点「出售选中物品」 |
| 任务页 | 五个固定任务：接取 / 追踪 / 上交 / 领取 |
| 常驻信息 | 当前金币、仓库总价值、最近一次操作结果 |

### 交易规则

| 规则 | 结论 |
| --- | --- |
| 购买去向 | 直接进仓库；仓库放不下时**不扣钱**并提示 |
| 出售来源 | **只允许仓库**；随身装备与背包不参与交易，规则层直接拦截 |
| 出售范围 | 整堆出售；右键可快速出售 |
| 二次确认 | 单次收购价 ≥ 10,000 金币时弹确认框 |
| 弹药规格 | 按 30 发一组买卖 |
| 库存与价格 | **固定价格 + 无限库存**；动态价格与库存刷新推迟（P-02） |

### 定价

| 项 | 规则 |
| --- | --- |
| 玩家买入 | 物品基础价值 × 数量 |
| 商人收购 | 基础价值 × **75%**（按整堆结算后四舍五入） |
| 启动资金 | 5,000 金币 |
| 中档一套 | PM 1,800 + 钢盔 4,500 + 背心 15,000 + 小背包 1,200 = **22,500** |
| 一发不错 | 一次成功撤离卖掉落约 **12,000 ~ 25,000**；死一套中档装备约两局赚回 |
| 保险柜焦点 | 金表 32,000 → 商人收购 24,000，约等于一套中档装备 |

### 商人常驻货架

| 商品 | 单价 | 商品 | 单价 |
| --- | --- | --- | --- |
| PM 手枪 | 1,800 | 9x19 标准弹 | 8 / 发（30 发一组） |
| AK-74 步枪 | 7,200 | 5.45 标准弹 | 25 / 发（30 发一组） |
| 小绷带 | 400 | 野战医疗包 | 9,000 |
| 钢盔 | 4,500 | 防弹背心 | 15,000 |
| 小型背包 | 1,200 | 突击背包 | 12,000 |

**完成判据**：空仓库光手出击 → 打 2~3 局卖东西 → 买下第一套 PM + 钢盔 + 背心 + 小背包 → 带着它再进战局。

**明确推迟**：多商人、声望、价格浮动、库存刷新、保险、跳蚤市场、4 级甲与更多武器（记录到第 7 节）。

## 4.7 批次 4：任务 + 存档 ✅

### 任务系统

- **固定 5 个任务**，不随机；入口在商人面板的「任务」页签。
- 状态机：`未解锁 → 可接取 → 进行中 → 可领取 → 已完成`。
- **同时最多进行 3 个任务，追踪 1 个**；HUD 左上角显示追踪进度，结算界面显示本局任务摘要。
- 「首次撤离」默认解锁；领取它的奖励后解锁其余 4 个。

| 任务 | 目标 | 奖励 |
| --- | --- | --- |
| 首次撤离 | 成功撤离 1 次 | 5,000 金币 |
| 清道夫 | 击杀 3 名敌人 | 8,000 金币 + 30 发 5.45 |
| 燃料回收 | 上交 1 个燃料罐 | 15,000 金币 + 20 发 5.45 |
| 满载而归 | 单局带出价值 ≥ 15,000 | 10,000 金币 |
| 毫发无伤 | 一局未受伤并成功撤离 | 8,000 金币 + 野战医疗包 |

**上交与领奖规则**：上交类任务从仓库扣除物品；奖励物品进仓库；
仓库满时拒绝领奖并提示，避免出现「钱到手、物品没地方放」的半完成状态。
奖励金额必须高于把物品直接卖给商人的收益，否则任务会立刻失去意义。

### 存档

存档只保存局外进度，**不保存战局中途状态**：

| 保存 | 不保存 |
| --- | --- |
| 金币余额 | 战局场景、AI、子弹与掉落箱 |
| 仓库 / 背包 / 弹药挂 | 战局倒计时与当前搜刮进度 |
| 装备槽 | 地面掉落与临时容器 |
| 任务状态与追踪目标 | 设置项（后续里程碑） |
| 战局进行中标记 | 云存档 |

**存储方案**：

- 路径：`Application.persistentDataPath` 下的 `raid_demo_save.json`，代码中只有相对文件名，没有任何绝对路径。
- 结构：`MetaSaveData` + `schemaVersion`；物品只写稳定 ID、数量、格子坐标与旋转，不写资产引用。
- 抗损坏：写入「临时文件 → 读回校验 → 备份旧档 → 替换主档」；主档损坏时自动回退到 `.bak`。
- 容错：未知物品 ID 跳过并记录，不让一份旧存档导致整局游戏无法启动。
- 自动存档时机：买卖、任务变化、撤离 / 阵亡结算、返回安全屋、退出游戏。

**强退防刷**：进入战局时先写入 `raidInProgress = true`；正常撤离或阵亡后清除。
若下次启动时标记仍在，就按阵亡处理——清空随身携带物并提示玩家，
使 Alt+F4 不能变成免费保险。

### 主菜单

| 情况 | 按钮 |
| --- | --- |
| 有存档 | `继续游戏` / `新游戏`（点击一次进入二次确认）/ `退出` |
| 无存档 | `开始游戏` / `退出` |

`新游戏` 会清空仓库、金币与任务进度，并把启动资金重置为 5,000。

## 5. 经济目标曲线（已验证）

| 项 | 目标值 | 当前实现 |
| --- | --- | --- |
| 一次成功撤离（搜 3~4 个箱子） | 15,000 ~ 40,000 账面价值 | 补给箱期望约 7,000 ~ 8,000，弹药 / 医疗 / 武器架更高 |
| 一套中档装备 | ≈ 20,000 | 22,500（PM + 钢盔 + 背心 + 小背包） |
| 死一次的回本时间 | 约两局 | 一次成功撤离卖出 12,000 ~ 25,000，两局覆盖一套中档装备 |
| 高价值焦点 | 「要不要为它多贪一局」 | 金表 32,000，收购 24,000，约一套中档装备 |

数值全部集中在 `TraderPricing.SellRate` 与物品资产的 `BaseValue`，
改经济曲线只需要改这两处，不涉及交易逻辑。

## 6. 明确不做

| 不做的事 | 归属 |
| --- | --- |
| 多个商人 / 声望 / 玩家间交易（跳蚤市场） | 不做，超出作品集范围 |
| 随机生成任务 | 不做，固定 5 个任务足够 |
| 枪械改装、皮肤 | 不做 |
| 保险箱（阵亡保留部分物品） | 留待 M7 之后 |
| 云存档 | 不做 |
| 战局中途存档 | 不做，只存局外进度 |
| 动态价格 / 库存刷新 | 推迟到 M7（P-02），当前固定价格 + 无限库存 |
| 收集图鉴 | 推迟到 M7；当前物品价值已足够支撑搜刮决策 |
| 4 级甲与更多武器 | 推迟到 M7 内容扩展；当前 2 级钢盔 / 3 级背心已能形成装备阶梯 |

## 7. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 存档被低估 | 已把序列化与文件 IO 分开：`MetaSaveMapper` 纯转换可测，`SaveFileStore` 单独验证损坏回退；新增字段时必须递增 `schemaVersion` 并补迁移 |
| 经济数值失控 | 买卖差价只有一个比率；实机确认一次撤离与一套装备在同一量级，后续只需调 `SellRate` |
| 界面工作量被低估 | 商人界面复用现有网格视图与运行时控件工厂，三个页签各自独立文件；M7 换预制体时只替换布局文件 |
| 玩家没有理由出门 | 五个任务 + 仓库总价值 + 高价值战利品共同提供目标；后续可在 M7 增加收集图鉴 |
