# 模块 09：游戏内角色选择

> 阶段：M7 批次 4 ｜ 状态：**已完成**（2026-09-13）
> 关联：`PresentationCatalog`、`PlayerCharacterBuilder`、`CharacterSelectScreen`、`MetaProgress`

---

## 1. 这一块解决什么问题

玩家第一次进游戏时，主菜单里的角色是固定的；想换一个形象只能去改预制体、重进场景。
批次 4 把它做成**局外可持久化的选择**：

```text
主菜单「选择角色」┐
                  ├─→ CharacterSelectScreen（12 张卡片 + 实时 3D 预览）
安全屋更衣镜 ─────┘              │
                                 ↓ 点击卡片
                         MetaProgress.SelectedCharacterId
                                 │
                                 ↓ 写入 JSON 存档
                  PlayerCharacterView.SetCharacter(prefab)
                                 │
                      安全屋 / 战局立即换模型
```

角色选择只改变表现，不改变移动、碰撞、生命、负重或武器数值——
“12 个角色”是外观选项，不是职业/属性系统。

---

## 2. 素材与预制体

| 项 | 取值 |
| --- | --- |
| 素材 | Kenney Mini Characters（CC0） |
| 角色数 | 12 个：`female-a..f`、`male-a..f` |
| 动画 | 每个 FBX 自带 384 段；12 个角色共用 `PlayerCharacter.controller` |
| 身高 | 统一缩放到 1.72 米，脚底对齐玩家根节点 |
| 材质 | `M_KenneyCharacter`（URP Lit + colormap.png，Point 过滤） |

构建入口：`RaidDemo/M7/重建玩家角色资产`。

- `character-male-a.fbx` 继续生成到旧的 `PlayerCharacter.prefab` 路径，保证安全屋与战局场景的引用不断；
- 其余 11 个角色生成到 `PlayerCharacter_<id>.prefab`；
- 重建完成后执行 `RaidDemo/M7/重建表现层资产`，把 12 个预制体写进 `PresentationCatalog` 的角色列表。

---

## 3. 存档

`MetaSaveData` 新增 `selectedCharacterId`，只写稳定 id（例如 `female-c`），不写显示名或资源路径。

- 旧存档没有该字段时，`MetaProgress` 回退到 `male-a`；
- 角色目录校验发生在表现层：id 找不到预制体时忽略这次选择，不会让存档损坏；
- 这是向后兼容的增量字段，`SchemaVersion` 保持 1。

---

## 4. 两个入口

### 主菜单

主菜单面板上的「选择角色」按钮调用 `RaidFlowController.ShowCharacterSelect()`。
主菜单本身保持显示，角色选择作为一层不透明界面盖在上面；关闭后回到主菜单。

### 安全屋更衣镜

西墙边的 `Facility_Wardrobe` 挂了标准的 `SafeHouseInteractable`（`Kind.Wardrobe`）：

- 它复用仓库、商人、出口同一套「最近设施 + 按 E」提示与分发；
- `SafeHouseBootstrap.Activate` 的 `Wardrobe` 分支调用 `OpenCharacterSelect()`；
- 界面打开期间 `SafeHouseUI.SetAuxiliaryPanelOpen(true)` 会阻止移动与射击输入；
- 关闭后恢复打开前的时间缩放与光标状态。

---

## 5. 实时 3D 预览

`CharacterSelectScreen` 右侧是一个 560×560 的 `RawImage`，由专用相机渲染到 `RenderTexture`：

- 预览台放在 `(10000,10000,10000)`，主相机 far clip 只有 300 米，因此不会看到它；
- 预览相机只看预览台附近 20 米，不需要额外 Layer；
- 选中模型缓慢自转，能看到正面、侧面与背面；
- 关闭或销毁界面时先清空 `camera.targetTexture`，再 `Release` RenderTexture，
  避免 “Releasing render texture that is set as Camera.targetTexture” 警告。

---

## 6. 扩展方式

新增一个角色只需要三步：

1. 把同骨架的 FBX 放进 `Assets/Game/Content/External/Kenney/MiniCharacters/`；
2. 在 `PlayerCharacterBuilder.Characters.cs` 的 `s_CharacterOptions` 里加一条 id / 显示名；
3. 依次执行 `RaidDemo/M7/重建玩家角色资产` 与 `RaidDemo/M7/重建表现层资产`。

当前限制：所有角色只有外观差异，没有属性差异，也没有逐角色立绘/头像；
这是刻意留给后续内容扩展的空间。
