## 2. 主题层的三个文件

界面代码从 M7 批次 4 起统一走 `Assets/Game/Modules/UI/Theme/`：

| 文件 | 职责 | 关键约定 |
| --- | --- | --- |
| `UiPalette.cs` | 唯一的色彩与尺寸来源 | 颜色以十六进制常量书写，改风格只改这里 |
| `UiSprites.cs` | 运行时生成九宫格贴图 | 圆角矩形 SDF + 描边 + 底部硬阴影，按需缓存 |
| `UiFactory.cs` / `UiButton.cs` | 构建画布、面板、文字、按钮、进度条 | 布局约定与旧工具一致：左上锚点、Y 轴向下 |

### 2.1 为什么贴图是"画出来"的

这套控件的形状规则只有三条（圆角半径、描边宽度、阴影高度），颜色全部来自 `UiPalette`。
做成 PNG 的话，改一次配色就要重导一遍图，而且颜色会在图片与代码里各存一份。
生成时按**参考分辨率的 2 倍**绘制（112×112、圆角 24px、描边 6px），再用
`pixelsPerUnit = 200` 抵消，于是描边在界面上正好是 3 像素、圆角正好 12 像素，边缘仍然锐利。

> **踩过的坑**：距离场用 `|x|`、`|y|` 判断对称性，坐标**必须先平移到贴图中心**。
> 第一版忘了平移，画出来的是"紧贴左下角的一小块圆角矩形"，
> 九宫格拉伸之后表现为"面板只剩左下角"（详见排障手册 M7-P-26）。

### 2.2 字体：TextMeshPro + Noto Sans SC

灰盒阶段用的是旧版 `Text` 组件 + 系统字体（决策 D-01 写明"等 M7 再统一换 TMP 与正式字体"）。
本批兑现这条：界面文字改为 **TextMeshPro**，字体为 **Noto Sans SC Regular**（SIL OFL 1.1，可随仓库分发）。

| 决定 | 原因 |
| --- | --- |
| 字体文件放进工程（8 MB，走 Git LFS） | TMP 需要读取字体文件本身来光栅化；系统字体（`Font.CreateDynamicFontFromOSFont`）没有可读数据，`CreateFontAsset` 会返回 null |
| 用**静态子集**字体资产而不是运行时动态扩页 | 编辑器重建时扫描项目界面文案，把用到的汉字一次性烘焙进 2048×2048 图集；运行时只查表，不再触发“图集满了再开新页”。这样做出的资产在播放与构建时都不变，也不会出现“字符表有记录、字形表没有 glyph”的缺字 |
| 设为 **TMP 项目默认字体** | 运行时创建的文字不指定字体也能拿到中文，界面代码不必持有字体引用，少一处会漏接的装配 |

生成入口：菜单 `RaidDemo/UI/重建中文字体资产`（`Assets/Game/Bootstrap/Editor/UiAssetTool.cs`）。
构建器会扫描 `Modules/UI`、`Modules/Meta`、`Modules/Data/Content`、内容物品资产与两个场景
（并跳过 C# 注释与测试代码），按 64pt 采样、6px padding 预烘焙到一张 2048×2048 图集。
TMP 基础资源由 `RaidDemo/UI/导入 TMP 基础资源` 导入——注意 Unity 会弹一次
"签名不在可信来源"的确认框，那是包内附带 unitypackage 的正常提示。

> **字体资产是静态子集，必须随界面文案一起更新。**
> 新增/修改界面文案后，执行 `RaidDemo/UI/重建中文字体资产`，再提交字体资产。
> EditMode 测试 `中文字体资产覆盖全部界面文案` 会用同一套字符扫描逻辑检查覆盖率；
> 如果漏了字，测试会直接列出缺字，而不是等到实机截图才发现。
> 旧的 `git restore` 运行时字形做法已经废弃：那份资产当时只有 253 个旧文案字形，
> 动态扩页失败时会让批次 4 的新汉字缺字/乱码（见排障记录 M7-P-28）。

### 2.3 进度条的统一入口

所有进度条都由 `UiFactory.CreateBar` 构建，再用 `UiFactory.SetBarProgress(fill, trackWidth, progress01)`
推进。填充矩形的锚点固定在底槽左边缘、轴心也在左边，宽度按「底槽宽度 - 两侧 3px 描边」再乘进度，
因此 0% 时完全隐藏、100% 时恰好落在描边内侧，不会从任何一边溢出。

**不要绕过这个入口直接改 `fill.rectTransform.sizeDelta`**：一旦有人只改宽度、忘了左边距或轴心，
就会出现 U-58 那种"橙色条从底板左侧长出去"的问题。

## 3. 稀有度色：为浅底另配一组变体

原来的白/绿/蓝/紫/金是为**深色背景**定的，压在奶油面板上会"发飘"（白字几乎看不见、金与黄糊在一起）。
做法不是改掉原色，而是在 `RarityPalette` 里增加一组**同色相、压暗降饱和**的浅底变体：

| 档位 | 深底（世界用） | 浅底（面板用） |
| --- | --- | --- |
| 普通 | `#E8E8E8` | `#7C7568` |
| 精良 | `#4CCE5A` | `#2F9A45` |
| 稀有 | `#3E8BFF` | `#2F6FD0` |
| 史诗 | `#A855F7` | `#8B3FD6` |
| 传说 | `#FFB300` | `#C08A00` |

世界里的伤害数字与地图标记继续用原色；物品格与提示文字用变体。两套都出自同一个文件，
改色仍然只有一个地方。

## 4. 主菜单改版（已完成）

从"叠在战局场景上的半透明遮罩"改为**不透明独立界面**：

```text
深绿松底色
  └ 居中奶油面板（900×660）+ 向下偏移 12px 的投影
      ├ 标题条（略深的纸）：RAID DEMO + 版本号
      ├ 副标题：3D 斜俯视搜打撤 · 卡通低多边形
      ├ 主按钮（青绿）：开始 / 继续游戏（Enter）
      ├ 次按钮（白）：新游戏（二次确认"再次点击确认清空进度"）
      ├ 提示行（警告色）：强退战局等一次性通知
      ├ 说明文字（可换行）
      └ 脚注：操作键位 + 单人 / 时长 / Esc 退出
```

交互仍然是**轮询鼠标**（与背包拖拽同一套），没有引入 EventSystem。
按钮的三种状态表现为：悬停抬起 2px 并微微提亮、按下换成无阴影贴图且文字下沉 3px。
