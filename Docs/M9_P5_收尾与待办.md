## 三、环境与脚本（下次直接可用）

- **批处理模式**（GUI 编辑器关闭时可用；GUI 打开时请用 `unity command --project-path ...`）：
  - 编译：`unity build 'D:\unity game\demo' --target StandaloneWindows64 -o 'D:\unity game\demo\Builds\StandaloneWindows64\RaidDemo.exe'`
  - 测试：`unity test 'D:\unity game\demo' --mode EditMode --output '...\p5_editmode_results.xml'`
  - 编辑器方法：`unity build 'D:\unity game\demo' --target StandaloneWindows64 --execute-method <类型.方法>`
    （例如重建中文字体：`RaidDemo.Bootstrap.Editor.UiAssetTool.BuildFontAsset`）
- **验收脚本**（`Library/ServerVerify/`，不入库）：
  - `p5_progress_check.ps1`（幕 1 / 幕 2 通过；幕 3 见 P-51）
  - `p45b_safehouse_check.ps1`（P4.5-b 回归，全绿）
  - `p5_diag_disconnect.ps1`（断线级联的诊断脚本：`-Scene safehouse|raid [-Reconnect] [-GraceSeconds N]`）
  - `p51_selfheal_check.ps1`（**断线自愈验收**：`-Scene safehouse|raid`，强杀乙 → 观察自愈 → 重启乙；
    两场三项判据全 PASS，见 §28.4）
- **测试存档**：`Builds\StandaloneWindows64\server_saves_p5test`（验收用）、`server_saves_diag`（诊断用）；
  默认目录 `server_saves` 里还留着早前误用 `-saveDirectory` 跑出的一份数据，可清理。
- **常用启动参数**：服务器 `-server -map GreyboxRaid -port 7799 -saveDir <目录> -grace <秒> -autostart <秒> -spawnzone`；
  客户端 `-connect 127.0.0.1 -port 7799 -nickname <昵称> -passphrase 246810 -autoroom [-autowalk]`。
  **注意**：`-saveDir`（不是 `-saveDirectory`）、`-spawnzone` 是**服务器侧**参数；
  `-watchdog <秒>`（0 = 关闭自愈，1~30 可调，默认 2.5）也是**服务器侧**参数（P-51）。
