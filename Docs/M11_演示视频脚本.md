# M11 · 演示视频脚本（6~8 分钟）

> 用途：秋招作品演示。目标成片 **6:30 ~ 8:00**，节奏按"单机 2 分钟 + 联机 2 分半 +
> 热更与分发 2 分钟 + 收尾 30 秒"分配。
> 所有命令与菜单路径都来自仓库现状；敏感信息（口令、公网 IP）在录制时替换成占位符值。

---

## 1. 录制前准备

**环境**

| 项目 | 建议 |
| --- | --- |
| 分辨率 / 帧率 | 1920×1080 @ 60fps（游戏窗口 Full HD + Play Maximized 是验收过的组合） |
| 录制工具 | OBS 或系统录屏；录游戏窗口而不是全屏，避免桌面杂物入镜 |
| 布局 | 主画面 = 游戏窗口；需要同屏看两台客户端时用画中画（左右各半屏） |
| 关闭 | Unity 编辑器、多余浏览器标签、聊天软件通知 |
| 音量 | 系统音量 60%；游戏音效是演示的一部分（枪声、搜刮、结算音） |

**预先启动的进程**（录制时不必现场敲命令，提前拉起来）

```powershell
# 1) 服务器：演示房间、8 分钟战局上限、20 秒后自动开局（省掉手动点出口）
RaidDemo.exe -server -port 7777 -room 演示房间 -autostart 20 -raidDuration 480 `
    -dashboardPort 8080 -discoveryPort 47777 -saveDir demo_saves -logFile demo_server.log

# 2) 客户端甲 / 乙（同一台机器跑两个，昵称必须不同）
RaidDemo.exe -connect 127.0.0.1:7777 -nickname 甲 -passphrase 246810 -autoroom
RaidDemo.exe -connect 127.0.0.1:7777 -nickname 乙 -passphrase 246810 -autoroom

# 3) 本机更新源（热更片段要用；口令换成你自己的）
RaidDemo.UpdateSource.exe --root <更新源目录> --port 8090 --token <更新源口令>
```

> 录制前先跑一遍 `Tools/Lobby/verify/p6_version_handshake_check.ps1`，确认两端版本一致，
> 免得录到一半发现进不去房间。

**构建产物**：`Builds/Client/1.0.0/`（Release 归档版）。不要用编辑器直接录——
编辑器里没有"启动器 + 更新源"这条链路。

| 0:20–0:50 | 安全屋全景 → 商人 → 仓库 → 靶子 | "进图之前的一切都在场景里，而不是一个菜单：买卖、任务、试枪、选图。" | 依次走近商人（`E`）、仓库（`E`）、靶子（打两枪） |
| 0:50–1:20 | 出口选图 → 加载进战局 | "出口就是出击口，选好地图再进去。" | 走到出口按 `E`，选工业区 |
| 1:20–2:00 | 搜刮读条 → 双击进背包 | "开箱要站定两秒，移动就打断——搜得越多，暴露越久。" | 开两个箱子，双击把战利品收进背包 |

| 3:20–4:00 | 共享安全屋：两个角色同屏 | "联机首站是同一间安全屋，队友就站在你旁边。" | 两个客户端在屋里走动、面对面 |
| 4:00–4:40 | 房主走到出口 → 全员回屋门禁 → 出击 | "只有全员回到安全屋，房主才能从出口选图——这条门禁由服务器判定。" | 让乙先在屋里，甲去出口选图 |
| 4:40–5:40 | 两人战局：分头搜刮、交火、各自撤离 | "两人各自撤离互不影响；服务器按同一套规则裁定搜刮、伤害与撤离。" | 甲、乙各撤离一次，切到服务器日志看结算 |
| 5:40–6:10 | 服务器状态页（浏览器） | "服务器带一个只读状态页：房间、玩家、日志都能看。" | 浏览器打开 `http://127.0.0.1:8080/` |

## 3. 录制清单（拍完自查）

- [ ] 0:20 段能看到 `E` 交互提示里的名称（商人 / 仓库 / 出口）
- [ ] 1:20 段搜刮读条完整走完，并且有一次"移动被打断"的镜头
- [ ] 2:00 段能看到护甲耐久下降与体力弧变化
- [ ] 3:20 段两个角色同屏（证明"同一间安全屋"）
- [ ] 4:00 段出现"全员回屋才能出击"的门禁提示（乙没回屋时甲点出口会被拒）
- [ ] 6:50 段日志里出现 `资源已生效（<内容版本>）`
- [ ] 7:20 段提示文案里**同时出现两个版本号**
- [ ] 全程没有桌面、聊天软件弹窗、终端里的公网 IP 与口令

## 4. 后期提示

- **加速**：菜单 ⑤ ⑥ 的构建过程 4~8 倍速，只保留"开始 / 完成"两帧。
- **字幕**：关键术语打字幕（服务端权威 / 增量更新 / 版本握手）——面试官很可能静音看。
- **打码**：更新源面板口令、公网 IP、`ssh` 会话一律遮挡，写成 `<更新源口令>`、`<服务器IP>`。
- **画中画**：联机段用三窗口布局，比反复切窗口清楚；单机段全屏。

## 5. 备用素材（某段实在录不出来时）

| 片段 | 替代方案 |
| --- | --- |
| 联机同屋 | 用 `Builds/HandshakeCheck/` 脚本产出的服务器日志截图，展示"房间已创建 / 玩家进入战局" |
| 资源热更 | 用热更日志里的 `资源已生效` 与服务端面板截图，配一句"这段是加速播放" |
| 版本握手 | 直接贴 `Tools/Lobby/verify/p6_version_handshake_check.ps1` 的输出（6/6 PASS） |
| 战斗手感 | 录不到满意的交火镜头时，用 AI 调试可视化（`F1`）讲视野锥与听觉圈的设计意图 |
